# WIPP

Application React Native + Expo (Android et iOS). Les cinq onglets sont des coquilles vides.

## Ouvrir sur un appareil

1. Installer [Expo Go](https://expo.dev/go) sur le téléphone.
2. Depuis ce dossier :

```bash
npm install
npx expo start
```

3. Scanner le QR code avec Expo Go (Android) ou l’appareil photo (iOS).

`npm run android` et `npm run ios` ouvrent un émulateur lorsqu’il est disponible.
